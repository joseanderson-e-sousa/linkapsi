# Linkapsi

Uma ferramenta da PsicoMachine.

Fundação em Next.js com App Router, React, TypeScript, Tailwind CSS e ESLint.
O código fica em `src/` e o alias `@/*` aponta para `src/*`.

## Executar localmente

Requer Node.js 20.9 ou superior e npm.

```bash
npm install
npm run dev
```

Acesse http://localhost:3000.

## Validar

```bash
npm run lint
npm run build
```

Para executar o build de produção, use `npm start` após `npm run build`.
